## How it runs

`main.ts` (Node 22, standard library only) copies `entry.png` byte-for-byte to
`$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`), checking the PNG magic bytes,
the 1 MiB size limit, and verifying the copy matches the source.
